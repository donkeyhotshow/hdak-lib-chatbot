# ХДАК Чат - Анализ функциональности поиска в каталоге

## Ответ: ДА, чат может сам искать в каталоге!

Система работает в **двух режимах автоматического поиска**:

---

## 1. Режим 1: Поиск по явному намерению (Catalog Search)

Когда пользователь задает вопрос о **поиске книги**, чат **автоматически** запускает поиск в каталоге.

### Как это работает:
```
Пользователь: "Знайди книгу 'Вий' "
              ↓
              detectSearchIntent() находит намерение
              ↓
              searchCatalog() запускается автоматически
              ↓
              Результаты встраиваются в контекст для ответа
              ↓
Ответ: "Знайшов... [результаты из каталога]"
```

### Распознаваемые паттерны поиска:

**По названию книги:**
- "Знайди книгу 'Вий'"
- "Шукаю книгу Мертві души"
- "Є у вас «Война и мир»?"
- "Маєте книгу про історію?"

**По автору:**
- "Книги Шевченка"
- "Твори Франка"
- "Книги автора Кулаєв"

**По УДК (Универсальная десятичная классификация):**
- "УДК 821.161"
- "УДК 92.37.8"

**По теме/предмету:**
- "Книги про древний Киев"
- "Материалы по философии"
- "На тему Украины"

**По ключевым словам:**
- "Ключевые слова: искусство, живопись"
- "За ключовими словами: математика"

### Типы поиска:
- `title` - поиск по названию
- `author` - поиск по автору
- `general` - общий поиск
- `udc` - поиск по УДК классификации
- `subject` - поиск по теме
- `keyword` - поиск по ключевым словам

---

## 2. Режим 2: Умные рекомендации (Smart Recommendations)

Чат **даже когда не ищет** может предложить материалы из каталога автоматически.

### Как это работает:
```
Пользователь: "Расскажи мне про Киевскую Русь"
              ↓
              Система находит слово "про" / "про Киевскую Русь"
              ↓
              Автоматически запускает поиск по теме "Киевская Русь"
              ↓
              Находит релевантные материалы в каталоге
              ↓
Ответ: "Киевская Русь - это... 
        [РЕКОМЕНДАЦІЇ: За темою... знайдено схожі матеріали:
        1. Історія Київської Русі (2020)
        2. Культура Київської Русі (2018)
        3. ...]"
```

### Распознаваемые паттерны рекомендаций:
- "Розкажи про..." ✓ Ищет по теме
- "Що таке...?" ✓ Ищет определение + материалы
- "Поясни..." ✓ Объяснит + найдет материалы
- "Цікавлять мене..." ✓ Предложит материалы по интересам
- "Навчаюсь..." ✓ Найдет обучающие материалы
- "Вивчаю..." ✓ Предложит материалы для изучения
- "Пишу про..." ✓ Найдет источники для статьи
- "Досліджую..." ✓ Найдет исследовательские материалы

## 3. Технические детали реализации

### Файлы ответственные за поиск:

**`src/lib/catalog-search.ts`** - основной модуль
- Функция `detectSearchIntent()` - находит намерение поиска в тексте
- Функция `searchCatalog()` - выполняет поиск в каталоге
- HTML парсер - извлекает информацию о книгах из результатов

**`src/app/api/chat/route.ts`** - интеграция в чат
- Строка 259: `const intent = detectSearchIntent(safeMessage);`
- Строка 270-285: Запуск поиска при наличии намерения
- Строка 287-302: Запуск рекомендаций при упоминании темы
- Строка 305-345: Параллельное выполнение всех поисков

### Параллельное выполнение:

Система запускает **ВСЕ поиски одновременно**:
```
┌─────────────────────────────────────┐
│ Параллельное выполнение (async)     │
├──────────────┬──────────────────────┤
│ 1. Проверка  │ 2. Основной поиск    │ 3. Рекомендации │
│   доступности│    в каталоге        │    по теме      │
│   каталога   │                      │                 │
└──────────────┴──────────────────────┴─────────────────┘
                    Результаты объединяются
                    в контекст для LLM
```

Это делает ответы **очень быстрыми** - поиск в каталоге не блокирует ответ от LLM.

### Timeout защита:

Если каталог долго отвечает (> 3 сек), система продолжает работать без результатов каталога, чтобы не замораживать ответ пользователю.

---

## 4. Что передается в LLM?

После поиска в каталоге, система передает в `buildSystemPrompt()`:

```
[КАТАЛОГ: Знайдено 5 результатів за "Вий"
1. "Вий" / Гоголь Миколай / 1835
   Доступна електронна версія
2. Вий. Матеріали дослідження / Петренко И. / 2015
   Тільки у бібліотеці]

[РЕКОМЕНДАЦІЇ: За темою "фольклор" знайдено схожі матеріали:
1. Український фольклор (2019)
2. Демонологія в українській культурі (2018)
3. ...]
```

LLM видит эти результаты и может:
- Дать ссылку на полный поиск в каталоге
- Рекомендовать конкретные материалы
- Объяснить релевантность материалов
- Дать совет как искать дальше

## 5. Примеры работы

### Пример 1: Явный поиск
```
Пользователь: "Где найти книгу про украинскую историю?"
              ↓
Система:     Обнаружено намерение "title" - ищет про украинскую историю
              Поиск запущен параллельно с ответом
              ↓
Ответ:       "В нашем каталоге есть несколько материалов:
              1. Історія України (Субтельний, 2019)
              2. Політична історія України (Кульчицький, 2018)
              
              Полный поиск: [ссылка на каталог]"
```

### Пример 2: Умные рекомендации
```
Пользователь: "Расскажи про Киевскую Русь"
              ↓
Система:     Обнаружена тема "Киевская Русь"
              Параллельно запущен общий поиск по этой теме
              ↓
Ответ:       "Киевская Русь - это древнее государство на территории
              современной Украины...
              
              [РЕКОМЕНДАЦІЇ: За темою 'Киевская Русь' знайдено матеріали:
              1. Київська Русь (Толочко, 2017)
              2. Культура Київської Русі (Головатенко, 2019)
              3. ...]"
```

### Пример 3: Нет намерения поиска
```
Пользователь: "Как дела?"
              ↓
Система:     Намерение поиска НЕ обнаружено
              Без ненужного поиска в каталоге
              ↓
Ответ:       "У мене все добре! Як справи у Вас?
              Чим я можу допомогти?"
```
