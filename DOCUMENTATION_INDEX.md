## 📁 Исходный код

### Основные модули:

#### 1. **src/lib/catalog-search.ts** (250+ строк)
- `detectSearchIntent()` - детектирование намерения поиска
- `searchCatalog()` - поиск в каталоге
- HTML parsing функции
- SearchIntent и SearchResult типы
- 29 регулярных выражений для распознавания

#### 2. **src/app/api/chat/route.ts** (450+ строк)
- Интеграция поиска в основной API
- Параллельное выполнение searchPromises
- buildCatalogContext() - форматирование результатов
- Встроение в systemPrompt для LLM

#### 3. **src/lib/logger.ts** (130+ строк)
- Логирование с debug/info/warn/error
- Цветной вывод в development
- Сохранение логов в памяти
- Экспорт JSON для анализа

#### 4. **src/lib/retry.ts** (110+ строк)
- withRetry() для автоматического повтора
- Exponential backoff (1s, 2s, 4s, 8s)
- Умное определение ошибок для повтора
- Jitter для предотвращения "thundering herd"

#### 5. **src/hooks/use-intersection-observer.ts** (140+ строк)
- useIntersectionObserver() - видимость элементов
- useScrollDetection() - обнаружение ручного скролла
- scrollToElement() - умная прокрутка

#### 6. **src/hooks/use-speech.ts** (180+ строк)
- Speech Recognition с обработкой ошибок
- Логирование ошибок микрофона
- Автостоп после молчания

## ⚙️ Ключевые компоненты

### Распознавание намерения (detectSearchIntent)

```
┌──────────────────────────────┐
│ Входящее сообщение           │
├──────────────────────────────┤
│ "Знайди книгу 'Вий'"         │
└──────────────────────────────┘
         ↓
    29 регулярных выражений
         ↓
┌──────────────────────────────┐
│ SearchIntent                 │
├──────────────────────────────┤
│ {                            │
│   searchTerm: "Вий"         │
│   searchType: "title"        │
│ }                            │
└──────────────────────────────┘
```

### Параллельный поиск

```
Promise.all([
  checkCatalogAvailability(),  ← 100-500ms
  searchCatalog(intent),       ← 500-2000ms
  searchCatalog(topic, "gen")  ← 500-2000ms
]) 
Total: ~2 seconds (не 4+ как было бы без параллелизма)
```

### Встроение в LLM

```
systemPrompt = `
  ...базовая инструкция...
  
  [КАТАЛОГ: Знайдено 5 результатів
   1. Вий / Гоголь / 1835
   2. ...
  ]
`

LLM видит результаты каталога и может их использовать
```
